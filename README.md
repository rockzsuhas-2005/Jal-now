# JalNow MVP

A zero-cost local-first prototype for a water delivery marketplace.

## What works
- Customer booking for tanker water and drinking-water cans
- Order history and statuses
- Supplier portal: accept and progress orders
- Admin dashboard: orders, suppliers, status management
- Data persists in browser localStorage

## Run
Open `index.html` in a modern browser. For best PWA behavior, serve the folder from any static web host.

## Important
This is an MVP/demo, not a production marketplace. It does not yet include real authentication, GPS tracking, payment gateway, push notifications, supplier verification, backend synchronization, or legal/compliance workflows.
